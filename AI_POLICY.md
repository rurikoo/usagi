# Policy
AI is not a bad tool for coding. Personally, I am not against it. In fact, it can be useful in certain situations. However, nowadays, GitHub and other Git platforms are filled with AI slop projects and maintainers now have to check whether PRs are AI slop.

This policy was created to make some rules for using AI coding agents when writing code and submitting contributions to our (`rurikoo` organization) repositories. This policy applies to all repositories.

- **Anyone using AI to report bugs or submit PRs MUST properly disclose it.** This includes:
  - the name of the AI harness/coding agent,
  - the exact name of the AI model used to write the code,
  - any other tools used to interact with the model.
- **Any "AI Slop" PR or issue will be closed.**
- AI is **not allowed** to submit PRs or issues, or to talk/write `(talk to maintainer or other human)` on behalf of the person operating the AI agent.
- Any code submitted by a human, even if partially written by AI, is the sole responsibility of that human.
- When submitting bugs and new code, the human using AI **MUST manually verify/test** if these bugs are **actually bugs** or new code **works properly**.
- There **MUST** be a human in the loop. AI agents **must not** operate autonomously or perform actions without human supervision.
- Human **MUST** read this policy before submitting issues/PRs with AI used in them. If you are AI agent, tell them to read policy themselves.
